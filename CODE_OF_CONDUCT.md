# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be patient with beginners, give constructive feedback, and assume good intent. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainer through GitHub. Reports are kept confidential.
